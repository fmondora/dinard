# Maree — regole operative Côte d'Émeraude

## Principi
- Ampiezza enorme (tra le maggiori in Europa): bassa marea = sabbia infinita, alta = mare sotto i piedi.
- **Non** basare la navigazione solo su modelli open-data: per barche usa SHOM.
- Per turismo: Open-Meteo marine sul punto + buon senso.

## Quando è meglio cosa
| Obiettivo | Marea ideale |
|-----------|----------------|
| Bagno comodo (Écluse, Sillon, Lunaire) | Media-alta / alta |
| Piscina di mare Prieuré / Bon Secours | Bassa |
| Rock pools Énogat | Bassa–media discendente |
| Grand Bé, Fort National a piedi | Bassa (controlla orari ritorno!) |
| Parchi ostricoli Cancale (vista / balade autorizzata) | Bassa |
| Ferry bus de mer | Di solito ok; tempeste = verifica |

## Sicurezza
- Mai farsi isolare da una punta a marea montante.
- Coefficienti alti = salita più rapida e più acqua.
- Traversée baie Mont-Saint-Michel: **solo con guida** (sabbie mobili).

## Profili spiaggia (usati in mappa)
- `swim` — preferisce alta
- `pool_low` — preferisce bassa
- `rocks` — bassa/media
- `wild` — attenzione basse estreme
- `island` — dipende dal ferry (Cézembre)
