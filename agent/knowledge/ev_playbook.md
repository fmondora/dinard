# Auto elettrica — playbook da Dinard

## Principio
Ogni leg >15–20 km: verifica autonomia + sosta logica (pasto o attrazione).

## Colonnine prioritarie (già in mappa)
| Dove | Perché |
|------|--------|
| Halles / centro Dinard (Sodetrel) | Base, Type2 notte/giorno |
| Barrage Rance (EDF) | Vicino base est |
| La Richardais Freshmile | Vicino pernottamento |
| Power Dot Av. Briand St-Malo | CCS rapida, multi-stallo |
| IZIVIA Madeleine / Allende | CCS 150–200 kW |
| Power Dot St-Méloir | Verso Cancale, ~200 kW |
| DRIVECO Saint-Briac | Costa ovest corta |
| Ionity Plouër-sur-Rance 350 kW | Day trip / rientro A84–N176 |

## Destinazioni tipiche
| Destino | Strategia EV |
|---------|----------------|
| Saint-Malo Intra-Muros | Ferry a piedi da Dinard **oppure** park extra-muros + piedi (EV in sosta) |
| Cancale / Grouin | Andata-ritorno ok se pieno; se dubbio 15–20 min CCS St-Méloir |
| Cap Fréhel / La Latte | Pieno a Dinard; verifica colonnine St-Cast/Matignon se residuale basso |
| Dinan | EV + passeggiata centro; mercato giovedì |
| Mont-Saint-Michel | EV; park La Caserne + navetta; Ionity se serve rapida sul percorso |

## Preferenze ospite
- Non scendere sotto ~20%
- Preferire una sosta pasto+CCS piuttosto che stress residuale
