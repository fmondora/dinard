Opzione A — Google My Maps (consigliata, tutti i pin insieme)
  1. Apri Google My Maps e fai login
  2. Clicca Crea una nuova mappa
  3. Nel primo layer: menu ⋮ → Importa
  4. Scegli il file dinard-google-mymaps.csv oppure dinard-mappa.kml
  5. Se CSV: colonna posizione = Latitude + Longitude; nome = Name
